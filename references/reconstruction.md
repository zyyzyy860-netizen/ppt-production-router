# Image and PDF reconstruction

Use `GordenImage2PPTX` only when the starting point is an image-format deck, slide screenshot, or PDF page and there is a real need to change it.

Run the reconstruction on one representative page first. Compare it side-by-side with the source and inspect the recovered text, background repairs, fonts, and line breaks. Treat decorative art, diagrams, and charts as images unless the result proves they are editable objects. Rebuild a frequently updated chart natively rather than repeatedly reconstructing it from a bitmap.
