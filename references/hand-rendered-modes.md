# Hand-rendered modes

Use this reference when the presentation should feel illustrated rather than templated.

## Choose the visual material

| Mode | Best for | System |
|---|---|---|
| Blackboard chalk | Teaching, explainers, processes | charcoal board, chalk white, 3–4 semantic chalk colors, imperfect lines, wooden edge only when it helps the classroom cue |
| Black-and-white ink | Argument, research, reflective or cultural topics | white paper or pale gray, black brush marks, one restrained accent, generous whitespace |
| Watercolor | Lifestyle, nature, soft narrative | paper texture, pigment bleed, hand-painted illustrations, sparse callouts |

Use one mode per deck. A subject-derived illustration, line, or diagram should carry the visual interest; do not add cards merely to make the page busy.

## Delivery truthfulness

### Default editable PPTX

Use native PowerPoint shapes/text or a static HTML deck with literal editable text. Keep headings, labels, process arrows, tables, and charts native. Generated watercolor or chalk art may be used as a replaceable background or isolated image object. This is the default for a topic-only request.

### Image-first final visual

Use `baoyu-slide-deck` when a consistent illustrated page is the product and future text changes are unlikely. It creates whole-slide images, then merges them into a PPTX. It is appropriate for a finished reading deck or video insert, not for a promise of element-by-element PowerPoint editing.

## Composition rules

- Build a 2–3 slide visual vocabulary before scaling: e.g. chalk arrows + color-coded bubbles + one hand-drawn subject object.
- Assign each accent a stable role: yellow for subject/energy, blue for process, green for nature/approval, pink for contrast or caution.
- Keep text sparse and legible at presentation distance. Handwritten styling must not reduce readability.
- Give diagrams real structure: arrows encode sequence, size encodes emphasis, and labels state actual concepts.
- For all editable decks, prototype and open a cover, a process slide, and the densest slide before creating the full deck.
