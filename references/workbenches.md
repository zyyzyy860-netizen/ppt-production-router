# Workbenches and deployments

These are optional products, not prerequisites for making a strong deck.

- Presenton: self-hosted or desktop presentation app with templates, editor, API, and editable export. Requires an explicit choice of local app/Docker deployment and model provider.
- LRriver/AIPPT: web workbench for controllable generation, page editing, and PPTX export. Requires explicit setup and ongoing runtime maintenance.
- PPTAgent/DeepPresenter: agentic research-to-presentation framework. Its Windows setup uses WSL and may involve Docker, local models, and external search/PDF/image services.

Before installing or starting any of these, confirm the user wants the application itself—not merely a single presentation—and identify data/privacy, model-key, and runtime requirements.
