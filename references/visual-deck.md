# Visual deck route

Use this route for a live talk, a filmed screen demo, or a deck primarily watched in a browser/PDF.

- Choose `codex-slides` for an end-to-end studio, fast visual iteration, local project state, and PPTX/PDF export.
- Choose `frontend-slides` when visual direction needs explicit comparison and a custom web-presentation result is the priority.
- Choose `guizang-ppt-skill` for editorial-magazine or Swiss-grid presentation language, presenter mode, and rehearsal.
- Choose `baoyu-slide-deck` when the desired artifact is intentionally image-first and text is unlikely to be revised afterward.
- Choose `baoyu-design` when a one-off HTML visual system, mockup, or unusually art-directed slide is needed.

Build the outline before rendering. Lock a single style direction, use a repeatable grid, and preview the actual rendering at the presentation resolution. For a recorded video, make the first 3–5 seconds visually decisive: one promise, one outcome, and no tool-list slide.
